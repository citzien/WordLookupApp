# 单词助手（Word Lookup App）

一个面向安卓手机的单词查询应用，专门解决「纸质书上的单词」：
拍一张照片 → 百度 OCR 识别 → 点击照片上的单词 → 自动查询中文意思、英文释义、同义词（含例句）、近义词（含例句）。

## 功能

- 手动输入单词查询：中文意思、英文释义 + 音标
- 同义词 / 近义词分别列出，每个词都带一句英文例句和中文翻译
- 拍照识别：调用系统相机拍摄课本/试卷，百度智能云 OCR 识别英文单词（含位置信息）
- 点词即查：识别出的单词在原图上画框，点击照片上的单词直接查询
- 查询后可以一键「返回继续识别」，照片和识别结果不丢失
- 相册识别、最近查询历史（最近 12 个词）
- OCR 设置页：百度 API Key / Secret Key 在 App 内填写，只保存在本机

## 技术栈

| 部分 | 方案 |
| --- | --- |
| 语言/UI | Kotlin + Jetpack Compose (Material 3) |
| OCR | 百度智能云 · 通用文字识别（含位置信息版） |
| 同义词 | Datamuse API（rel_syn） |
| 近义词 | Datamuse API（ml，意思相近的词） |
| 例句 + 中文翻译 | Tatoeba 语料库（英文例句自带中文翻译） |
| 中文翻译 | MyMemory 免费翻译 API（备用） |
| 英文释义/音标 | Free Dictionary API（dictionaryapi.dev） |

除百度 OCR 外，其余数据源全部免费且无需注册。

## 申请百度 OCR（必做，免费，约 10 分钟）

### 第 1 步：注册并登录百度智能云

1. 浏览器打开 https://console.bce.baidu.com （百度智能云控制台）
2. 没有百度账号先注册一个（手机号即可），然后登录
3. 首次使用会要求**实名认证**：控制台右上角「头像 → 实名认证」，选「个人认证」，
   按提示用身份证/银行卡完成（免费，几分钟）

### 第 2 步：开通文字识别

1. 控制台搜索框输入「文字识别」，进入「文字识别」产品页
2. 点「立即开通」/「免费开通」（每个接口都有免费额度，个人学习足够）
3. 也可直接访问产品页：https://ai.baidu.com/tech/ocr

### 第 3 步：创建应用，拿到两个 Key

1. 在「文字识别」控制台左侧点「应用列表」（或「管理应用」）
2. 点「创建应用」：
   - 应用名称：随便填，比如「单词助手」
   - 应用类型：选「移动应用」或「浏览器」都可以
   - 接口选择：勾选「文字识别」相关接口（建议把通用文字识别的几个都勾上）
   - 点「立即创建」
3. 创建成功后回到「应用列表」，找到刚建的应用，点「查看密钥」
4. 复制页面上的 **API Key** 和 **Secret Key** 两个字符串

### 第 4 步：填进 App

1. 打开 App → 进入「拍照识别」页面
2. 点右上角「设置」图标（⚙️）
3. 把 API Key 粘贴到「API Key」输入框，Secret Key 粘贴到「Secret Key」输入框
4. 点「保存」，然后拍照识别即可

> 注意：本 App 调用的是「通用文字识别（含位置信息版）」接口（general），
> 因为需要拿到每个单词在照片上的位置，才能实现点照片上的单词查询。
> 申请时勾选「文字识别」相关接口即可，免费额度按接口单独计算。

## 打开与运行

1. 安装 Android Studio（Ladybug 或更新）
2. File → Open，选择 WordLookupApp 文件夹
3. 等待 Gradle 同步完成（本项目已配置 Gradle 8.10.2 wrapper + 国内镜像；JDK 17 已写入 gradle.properties）
4. 用安卓真机运行（Run ▶），或 构建 → 构建 APK(s) 直接出安装包
5. 产物位置：app/build/outputs/apk/debug/app-debug.apk

## 权限说明

- 只需要 INTERNET 权限（查询 API + 百度 OCR）
- 拍照调用系统相机 App，不需要相机权限；相册使用系统照片选择器，不需要存储权限

## 常见问题

- OCR 识别还不稳定：当前版本对带横线/格子的图片识别效果一般，正在优化中；可尝试裁剪 + 去除线条 + 切换百度/腾讯引擎
- 识别报「还没有配置 API Key」：去 OCR 页右上角设置填写百度 Key
- 识别慢或失败：百度是云端 OCR，需要联网；光线好、字大一点成功率更高
- 中文意思空白：MyMemory 免费接口偶尔限流，点「重试」即可
- 某几个词没有例句：Tatoeba 语料库里没有该词的例句，属正常现象
- 生僻词没有英文释义：dictionaryapi.dev 查不到，只显示中文意思和同义词
